# Magic Storage
Magic Storage is an Android application that aims to make image deletion and organization a cup of tea.
This app must have the rights for reading, moving and deleting images into the smartphone

## UI
Magic storage takes inspiration from Tinder, using right swipe and left swipe for saving or discarding an image.
Once a day (or a Week or every n days, configurable in settings), the app sends a notificaiton that images must be selected. Cliccing onto the notifications the app opens and shows the last images/pictures saved on the smartphone, later than the last image selection.
The images are showed once at a time until the job is done.
For every image the commands are:
- swipe right: keep image
- swipe left: delete image
- swipe up: go to previous image
- swipe down: go to next image
- button in the bottom left are of the page: archive (repropose this image on the next image selection task)

## Storage
Deleted images are moved into a thrash folder abd are deleted after one week spent in the trash.

## Later developements
For the future implementations, this app must propose similar images as different versions of the same one allowing selection of the preferred one and deleting the others.
